# 风格库

每篇封面只选 1 种主风格；正文配图使用同一风格的简化表达。所有风格默认在 slate-amber
色板内展开（蓝灰为骨、琥珀点睛、米白纸面），差异在材质、镜头与视觉关系，不在配色
失控。

## 1. human-story-editorial 人物现场

- 适用：工人、消费者、司机、商户等具体人的处境（裁员、用工争议、涨价中的普通人）
- 锚点：明确成年的原创人物；真实编辑摄影质感；场景光源可解释；皮肤、衣料、环境的
  细微缺陷；用目光、距离、未完成动作留叙事悬念
- 避免：棚拍磨皮、摆拍感、无关姿势、多人抢焦点、名人相似、正对镜头的脸部特写

## 2. concept-metaphor 概念隐喻

- 适用：行业判断、涨价、裁员、商业模式之争等抽象观点
- 锚点：从文章核心矛盾推导出的原创隐喻；大面积留白；主体间有清晰的尺度、材质或
  方向冲突；一个主色关系加一个琥珀强调色；第二眼才读到的细节
- 避免：把标题修辞直接画成字面场景；灯泡、棋子、棋盘、天平这类用滥的象征；无法
  一句话解释的超现实堆砌

## 3. evidence-collage 证据档案

- 适用：涨价函、合同、单据、截图、文件在叙事中承担分量的选题
- 锚点：纸张、打印物、实物的分层与前中后景；一个证据为主、其余辅助；折痕、裁切线、
  颗粒感；文件一律做"无字或仅含抽象排版线条的类文件"处理
- 避免：复刻真实红头文件、公章、签名与真实抬头；密集小字；随机拼贴；真实品牌名
  出现

## 4. workbench-map 图解工作台

- 适用：框架、方法论、机制解释类内容
- 锚点：米白纸面；卡片式信息区域与路径关系；手绘线条、便签、克制的模块色；大留白；
  只做意象化工作台，不追求精确流程
- 避免：儿童教材感、胶带装饰过多、箭头与图标堆砌、小字密集、把封面塞成正文级流程
  图

## 5. data-terminal 数据盘面

- 适用：价格、财报、行情、库存等数据信号驱动的选题
- 锚点：深灰蓝空间；一条清晰的信号或数据路径；琥珀色只承担状态强调；真实设备、
  控制面板的材质感；可有远景成年人物做尺度
- 屏幕只许出现抽象的图形轮廓，不允许可读的具体数字、曲线标注
- 避免：代码雨、霓虹网络、发光大脑、赛博朋克城市、屏幕小字、光效泛滥

## 6. high-concept-poster 高级概念海报

- 适用：强观点、主张、宣言式封面，文字本身承担第一视觉
- 锚点：`short-exact` 主文字（≤8 汉字、逐字来自文章）大而醒目、处于安全区；第一眼
  读到主题，第二眼理解隐喻；只选一种视觉关系（连接、扩散、压迫、托举、撕裂、照亮、
  分裂、对抗、聚焦、回声、上升、坠落等）；克制印刷质感
- 避免：简单字效、PPT 封面感、广告页、廉价插画、固定模板、二维码/Logo/联系方式、
  错字乱码

## 内容匹配（用户未指定时）

| 内容 | 优先风格 |
|---|---|
| 具体人的故事与处境 | human-story-editorial |
| 抽象判断、行业观点 | concept-metaphor |
| 文件、函件、证据叙事 | evidence-collage |
| 框架、方法论、机制 | workbench-map |
| 价格、财报、行情数据 | data-terminal |
| 强观点、宣言 | high-concept-poster |

用户明确指定风格时以用户为准，不因"内容标签"自动更换。
