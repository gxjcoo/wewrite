# 视觉基因

账号长期识别度的来源。style.yaml 决定账号调性，本文件是它在图片上的延伸。

## 默认基因

1. 一个主要视觉钩子，第一眼只出现它
2. 清晰轮廓或明确的颜色对比
3. 真实、可触摸的材质
4. 轻微不完美与现场感，拒绝塑料光泽
5. 一层可供读者继续解释的叙事悬念
6. 手机端缩略图仍能识别主题
7. 同篇图片共享构图语法与色彩关系

默认回避：通用 AI 蓝紫渐变；发光大脑、机器人握手、无意义粒子；PPT 首页感、课程封面
感、电商广告感；过多标题标签；与论点无关的漂亮场景；每张图相同姿势、相同居中构图。

## 70% 稳定 / 30% 变化

跨文章保持稳定（约七成）：

1. slate-amber 颜色关系：蓝灰为骨、琥珀点睛、米白纸面
2. 写实质感与光线逻辑（方向侧光、可读阴影）
3. 平视、35-50mm 的镜头语言
4. 留白、安全区与简洁版式
5. 系列编号与命名规则（cover.jpg / figure-N-{slug}.jpg）

随文章变化（约三成）：

1. 视觉主体
2. 场景与道具
3. 核心隐喻或视觉关系
4. 冲突的表达方式
5. 天气、光线时段与动作瞬间

色板不是绝对禁令：选题明确需要其他色系时（如强情绪场景）允许偏离，但要写入契约，
且一次只动一个维度。

## 参考图

| 用途 | 保留 |
|---|---|
| direct | 主体身份、必须复现的构图 |
| style | 线条、材质、光线、空间规则 |
| palette | 颜色关系与占比 |

只提取高层规则重新组织，不复制参考图的独特版式与文案；路径只有在文件真实存在时才
记录。

## 人物边界

明确成年、原创身份、自然比例、真实皮肤与具体环境光；用视线、姿态、遮挡、距离、道具
建立情绪；完整遮盖、非露骨；排除真实名人、著名角色、品牌形象。
