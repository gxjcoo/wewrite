# 质量门槛

生成后必须打开实际图片：正常尺寸和约 25% 缩略图尺寸各检查一次。没有检查真实产物，
只能报告"未验证"，不许声称通过。

## 12 项评分（0-2 分，不适用标 N/A 并说明原因）

| 项目 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| 主题识别 | 看不出主题 | 需要解释 | 第一眼明确 |
| 单一焦点 | 多元素争抢 | 焦点略弱 | 单一明确 |
| 内容对应 | 与文章冲突 | 大致相关 | 精确对应 |
| 文章专属度 | 换到另一篇仍成立 | 少量专属细节 | 主体/冲突/场景至少三项来自本文 |
| 场景叙事 | 无动作或空间关系 | 有关系但弱 | 动作、空间与主张互相解释 |
| 平台裁切 | 关键内容被裁 | 边缘有风险 | 安全区清楚 |
| 文字质量 | 错字或不可读 | 可读但偏弱 | 准确清晰（textless 评 N/A） |
| 风格执行 | 通用模板感 | 部分执行 | 全画面一致 |
| 真实质感 | 塑料感、明显 AI 痕迹 | 基本自然 | 材质可信 |
| 系列一致性 | 像不同项目 | 部分联系 | 同篇统一且有变化 |
| 技术质量 | 变形、乱码、伪影 | 轻微问题 | 干净完整 |
| 事实安全 | 出现编造数据/品牌标识/伪造公章文件 | 有疑似元素 | 完全干净 |

分数只用于比较同类候选，不设跨任务统一线，不据此承诺打开率。

## 硬失败（命中任一直接失败）

1. 核心主体或文章主题错误
2. 人脸、手部、产品结构明显变形
3. 关键内容落在裁切危险区
4. `short-exact` 文字缺失、错字、乱码或不可读
5. 出现可辨认的未授权名人、著名角色、品牌形象或真实品牌 logo
6. 出现可读的编造数据、真实文件红头/公章/签名的复刻
7. 参考对象发生明显身份漂移
8. 出现不适合公开文章场景的露骨内容

## 缩略图复检

把封面缩到约 25% 尺寸再看一次：主体、内容类型、视觉钩子是否仍可辨认。`short-exact`
文字是否仍读得出。答"认不出"即失败。

## 修订规则

1. 判定问题属于内容、构图、风格、文字、裁切还是技术伪影。
2. 只改相关提示词段落，保留已通过的锚点；同步更新契约版本。
3. 新文件命名：`prompts` 中新建 `NN-{slug}-v2` 段，图片输出新文件名（旧候选保留）。
4. 只重生成失败项，且相同原因只重试一次；已通过资产不重复生成。
5. 再次检查真实产物并记录结果。

禁止用程序化涂抹、覆盖、重绘去修补生成图中的文字；文字错误一律重生成。

## 状态

| 状态 | 含义 |
|---|---|
| 契约失败 | 契约与文章/用户硬约束冲突，未调用生图 |
| 通过 | 实际图片已检查，无硬失败 |
| 部分通过 | 有图片通过，也有失败或未重试项 |
| 未验证 | 只有提示词或调用记录，未检查实际图片 |
