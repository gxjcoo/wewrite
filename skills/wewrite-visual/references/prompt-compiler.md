# 提示词编译器

把契约、文章内容、风格和结构融合为一份完整提示词。禁止模板原样拼接，禁止保留未解析
占位符。提示词正文用英文；需要可见中文时逐字引用 `exact_text`。

## 每项资产的文件头

保存到 `artifacts.image_prompts` 时，每段提示词带 YAML 头，字段必须与契约一致：

```yaml
---
asset_id: figure-1
asset_type: cover        # cover | figure
platform: wechat
aspect_ratio: "2.35:1"
style: human-story-editorial
archetype: unfinished-moment
text_policy: textless
exact_text: ""
output: cover.jpg
---
```

## 8 段结构

按以下顺序写完整、自然的英文提示词，每段都要对应可见画面决定：

### 1. 任务 Task

生成什么平台、什么比例、什么用途的图（封面 / 内文配图，一张完整成图，非网格、非候选
拼版、非联系表）。

### 2. 内容契约 Content contract

原始标题、核心主张、目标读者、第一眼主题、第二眼洞察。均取自契约 brief，不添加文章
没有的信息。

### 3. 画面主张 Visual statement

一句话说明核心主体、动作或冲突，以及它为什么对应这篇文章。用两个问题自检：去掉标题
后画面是否仍表达本文特有的关系？换成无关文章是否几乎不用改？第二个问题答"不用改"就
回炉。

### 4. 构图 Composition

主要视觉中心、前景/中景/后景、留白、阅读路径、边缘安全区（关键元素距四边约 10%）、
缩略图轮廓。只允许一个主要焦点，辅助元素最多一层背景语境。

### 5. 视觉语言 Visual language

所用风格的材质、光线、颜色关系、线条与镜头语言。色板写 slate 蓝灰与 amber 琥珀的
具体关系（谁为骨、谁点睛、占比），作为渲染指导；色值数字不允许出现在画面中。

### 6. 文字 Text

- `textless`：明确要求画面不出现任何文字、数字、字母、标签、招牌。
- `short-exact`：逐字列出唯一允许出现的中文（≤8 汉字），说明字号层级与位置；禁止
  其他任何小字。

### 7. 平台适配 Platform adaptation

重申比例（aspect ratio 字样必须出现在提示词中）、裁切风险、手机端阅读。同篇多张时
说明本张如何继承主色、材质与镜头语言，以及信息功能上的变化。

### 8. 限制 Restrictions + 输出标准

账号特定禁用项与通用失败模式：

- 无文字策略下禁止任何文字、数字、字母、水印、平台标识、品牌 logo 与可读招牌
- 禁止通用 AI 蓝紫渐变、发光大脑、机器人握手、无意义粒子、PPT/课程/电商广告感
- 人物：明确成年、原创身份、自然比例；禁止可辨认的真实名人、著名角色、品牌形象；
  不要正对镜头的脸部特写与容易出错的手部特写
- 禁止复刻真实红头文件、公章、签名；屏幕、纸张上不允许可读的具体数据
- 只输出一张完整成图，不输出解释文字、网格或多候选

## 正文配图的附加要求

写清三项：文章位置（章节与读者问题）、图像答案（这张图解释什么结论/对比/处境）、
连续性（如何沿用封面的主色、材质和镜头语言并做简化）。

## 生成前检查

1. 全部占位符已替换，文件名与比例明确
2. 每项决定可追溯到契约、文章或用户原话
3. 提示词文件头与 `visual-contract.yaml` 无冲突
4. `short-exact` 的文字逐字对回文章
5. `textless` 提示词确实禁止了一切文字
6. 相对路径引用的文件真实存在
